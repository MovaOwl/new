# Словопад

Android-игра для заучивания английских слов. Слово падает сверху, а ты жмёшь правильный перевод, пока оно не упало. Три верных ответа, и слово выучено.

- В словаре около 2600 слов: самые частые английские плюс лексика по недвижимости и переговорам.
- Озвучка встроенным синтезатором речи Android, работает без интернета, если установлен английский голос.
- Прогресс хранится на телефоне.

## Установка

Открой страницу [Releases](../../releases/latest), скачай `Slovopad-*.apk` и установи. Новые версии ставятся поверх старой, прогресс не теряется.

## Сборка

APK собирает GitHub Actions при каждом пуше в `main` (`.github/workflows/build.yml`) и сам выкладывает его в Releases.

## Где что лежит

- `app/src/main/assets/index.html` — сама игра (HTML + JS).
- `app/src/main/assets/words.js` — словарь, формат `english|перевод`, по слову на строку.
- `app/src/main/java/.../MainActivity.java` — обёртка WebView, озвучка и вибрация.
