# Инструменты словаря

- `phrases/*.txt` — исходники фраз, формат `english|перевод`, по строке.
- `lem.py` — разбор фразы на слова словаря (лемматизация, служебные слова, многословные записи).
- `build_phrases.py` — собирает `app/src/main/assets/phrases.js` из всех `phrases/*.txt`:
  для каждой фразы считает слова-ключи, по которым она открывается.

Запуск: `cd tools && python3 build_phrases.py`

## Встроенный словарь (офлайн)
- `tools/dict/d001…d020.txt` — по строке на слово: `en|описание по-русски|пример1|перевод1|пример2|перевод2`.
- `python3 tools/check_dict.py` — проверка (все 5024 слова, без дублей).
- `python3 tools/build_dict.py` — собирает `assets/dict.js` и кладёт примеры во `tools/phrases/x_dict.txt`
  (только примеры, где каждое слово есть в словаре; служебные слова и имена — список BASIC в lem.py).
- Затем `python3 tools/build_phrases.py` — пересобирает `assets/phrases.js`; фразы с незнакомыми словами выкидываются.

## Лис (спрайты)
- Исходные листы от нейросети (JPG, зелёный фон или нарисованная «шахматка») режет `tools/fox/cut2.py` по сетке из `tools/fox/specs.json`:
  фон удаляется заливкой от краёв клетки (контур лиса — барьер), остатки шахматки — по многотонным островкам, зелёный ореол — despill.
- На выходе `assets/fox/<анимация>.png` — лента кадров, размеры в `FOX_META` (fox.js). Логика лиса — `assets/fox.js`.
